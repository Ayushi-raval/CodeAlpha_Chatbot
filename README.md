## 📖 About the Project

This chatbot reads what the user types and replies using predefined rules written with `if-elif` statements. It keeps chatting in a loop until the user says bye. I have not used any AI model , API or any other libraries here.

**Internship task:** CodeAlpha Python Programming Internship, Task 2 (Basic Chatbot). It takes input like "hello", "how are you" and "bye", and gives predefined replies.

---

## ✨ Features

- 👋 Replies to greetings like "hello", "hi" and "hey"
- 💬 Answers "how are you" and asks about your mood
- 🏷️ Tells its name, the current time and date
- 😄 Tells random programming jokes
- ❓ Has a `help` command
- 🚫 Gives a friendly reply when it doesn't understand
- 🚪 Exits when you type `bye`, `exit` or `quit`

## ▶️ How to Run

Make sure **Python 3** is installed, then run:

```bash
git clone https://github.com/Ayushi-raval/CodeAlpha_Chatbot.git
cd CodeAlpha_Chatbot
python chatbot.py
```

> 💡 On some systems, use `python3` instead of `python`.
